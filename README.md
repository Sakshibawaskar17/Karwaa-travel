# 🌍 Karwaa Travel Website

A modern, responsive travel booking website inspired by **Karwaa Hospitality**, designed to showcase premium travel experiences, curated tour packages, and personalized services — all in one place.

---

## ✨ Features
- 🧭 **Hero Section:** Eye‑catching banner with search functionality for destinations, check‑in/out, and travelers.
- 🚗 **Our Services:** Horizontal cards for Driver Assign, Tour Packages, Hotel Bookings, Transport Services, Customized Trips, and 24/7 Support.
- 🏖️ **Popular Tour Packages:** Grid layout featuring curated travel destinations with pricing and details.
- 📞 **Contact Info:** Integrated navbar with phone, email, and “Book Now” button for quick access.
- 💻 **Responsive Design:** Works seamlessly across desktop and mobile screens.
